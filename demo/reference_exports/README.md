# Exports de maquettes reçus

Ces archives ont été conservées ici pour garder les références avec le projet :

- `Accueil — ordinateur-html.zip` : accueil ordinateur et ses ressources.
- `Fiche produit-html.zip` : fiche produit et ses ressources.

Les README inclus dans les deux ZIP indiquent qu’il s’agit de maquettes visuelles. Le rendu dépend d’un runtime de conception; certains chemins `/_blob/...` sont construits à l’exécution et ne pointent pas vers les images présentes dans l’archive. Utiliser les exports pour comparer les choix visuels, pas comme code de production.

La démo de travail à montrer reste celle de [`../README.md`](../README.md), avec ses trois vues. Les archives n’incluent pas l’accueil mobile.
